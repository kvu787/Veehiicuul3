An inconsistent unused tail extension that still passes the old geometric seam check is rejected by the new editing contract. Existing file reading and ported curve validation remain unchanged.

The extension check requires k[i+N]-k[i] to equal k[N+p]-k[p] for i=0..2*p. Its tolerance is eight times double epsilon times the largest of 1, the two compared knot magnitudes and the period magnitude. Tessellate additionally requires the evaluated endpoint distance below 1e-5, as in the ported domain. These are floating-point validity tolerances, not mesh-reuse tolerances: reuse requires exact equality of the entire newly sampled boundary with the built boundary. Valid knots can still create intersecting or incorrectly nested shapes; surface generation keeps its existing topology checks and never repairs points/placements.
